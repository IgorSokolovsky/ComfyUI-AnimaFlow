Anima Generator + Anima Preview — Playground

Two decoupled nodes replacing the reference pack's single monolithic AiO node. The pipeline (sampling → highres → detailer → upscale) never renders UI itself — it broadcasts frames on a named channel; the Preview node is a small, separate, independently-resizable node that just displays whatever channel it's tuned to. This is the fix for the reference pack's "giant settings node with an embedded image panel that fights the graph's zoom" problem.

Agnostic inputs: Generator takes plain MODEL/VAE and, per pane, either a wired CONDITIONING or a STRING + CLIP fallback (hover the positive/negative rows below) — no proprietary bundled "Input" node required upstream.
