Control Panel & Loader Panel

Mockup for docs/control-panel-design.md — house theme, legacy-litegraph layout

One row = one control = one output dot, parked on that row's Y. Rows come from a fixed catalog (sampler, scheduler, seed, int, float, latent — and models on the second node) rather than being generic numbers. Split into two nodes because ComfyUI caches per node — a seed and a UNET in one panel means every seed bump reloads the model.

This mockup is live. Click a value or its ▾ to open the list, use ◀ ▶ to step one option at a time, drag across steps / cfg to set them, hit R and N on the seed, open a ⚙, and use + Add control / + Add loader to pick a new row from the catalog.

ComfyUI's own socket colours, so the dots read the same as every other node on the canvas. Python declares every slot wildcard; the frontend narrows the visible type so a wrong wire is refused at the wire, not mid-run.

Row anatomy

Name left, value right, dot pinned to the row's own Y — no slot column, so the node is exactly as tall as its rows.

On a list row, ◀ ▶ step one option at a time and the ▼ beside the value opens the full list below the field — option lists only.

On a seed row, R is a toggle: a fresh seed every run. N is a one-shot button: roll a new seed now and hold it fixed. ⚙ appears only on rows with more to say, and opens to the right — a different menu from the option list.

Control Panel rows have a grip on the left — drag to reorder. Each row keeps the output slot it was created with (hover a dot to see it), so rearranging the panel never touches a wire. The loader panel has no grip: three fixed loaders have no ordering worth dragging.

Deleting a row is the case that does disturb slots — confirm first when anything below is wired.

Two panels, not one

ComfyUI's cache signature is per node and propagates to everything downstream of any output. Mixing a seed row with a model row means a 10s+ reload on every tweak.

So: one panel per change-frequency tier. Two Control Panels is normal — a "tweak these" and a "set once".

On legacy litegraph, sampler_name is a canvas widget: right-click → Convert widget to input before it can be wired.
