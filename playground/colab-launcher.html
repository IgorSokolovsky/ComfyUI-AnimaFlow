05 Launch & Tunnel stopped ›

Starts ComfyUI in the background and opens a Pinggy tunnel. The status pill up top tracks the live server.

Off = whatever requirements.txt pinned for the checked-out ref. On = boot that frontend build instead (Restart to apply). Use this to go UP only. ComfyUI reports required_frontend_version from the ref's own requirements.txt, so a LOWER frontend always trips “Frontend version X is outdated” — to run an older UI, pin the ref above instead (v0.28.3 ⇒ 1.45.21) and leave this off, so core and frontend move together. FYI 1.47.10 filters canvasOnly widgets (seed's control_after_generate) out of subgraph promotion and the Parameters panel — PRs #12957/#13870/#13868, still true in 1.48.5. Unrelated: a custom DOM widget with no backing input slot (Pixaroma Resolution) can never be promoted onto a subgraph in ANY version — not a pin issue.
