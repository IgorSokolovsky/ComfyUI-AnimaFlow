AnimaFlow — LoRA Loader + shared Civitai browser

Mockup for docs/lora-loader-design.md. Everything is clickable: a row's name opens the picker, i opens the info panel, ⚙ opens settings, Browse Civitai opens the search/download browser. Panels below are shown expanded side-by-side rather than floating, so every state is visible at once.
What is a port and what is new. Rows, the searchable picker, missing-file marks, per-row trigger-word picking and the hash-based Civitai lookup all exist upstream (MIT © pixaroma) and are ported with attribution. Search and download are new — they are the two things upstream does not have, so they are where this mockup earns its keep. The Civitai metadata lookup needs no API key; only search and gated downloads may.
Three surfaces, one library. The LoRA Loader's browser is scoped to loras and the Loader Panel's to models — both are pickers that return a value to the row or slot that opened them. The toolbar modal is unscoped: it answers to nobody, and each result's destination folder comes from its own type.

stored as last / all / none — human label, raw key in state
↑ off hides every network affordance on this node — the ⓘ panel's lookup and the 🔍 button both go. One switch, and the node is provably offline (§9). Try it.
Dropped from upstream's dialog: Highlight colour — the pack has one house accent (THEME.md); a per-node override would break that on purpose. Set as default / Every Pixaroma node / Done — those three exist to paper over mixing per-node and global state. We already have Settings → AnimaFlow for user-wide prefs (docs/settings.md), so cross-node defaults live there and this dialog stays per-node. No footer buttons: edits apply immediately, ✕ closes.
Sizing — Class A. Height is content, never draggable; width resizable with a minimum. Note the reason differs from the Control Panel: this node has no per-row output sockets, so it could scroll — Class A is the owner's preference for a row-list node, not a structural necessity. See control-panel-design.md §7a and the comfyui-litegraph-node-sizing skill before writing any sizing code.
